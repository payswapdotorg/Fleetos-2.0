## Objective

The Control Plane is the layer that makes missions durable: a tenant-scoped
command bus with idempotency, retry and dead-lettering, and a mission runtime
whose state survives any process lifetime (checkpointed, event-sourced,
resumable), both built on the F211 transactional seams (UnitOfWork +
TransactionalSession + OutboxPort) as TYPE-level seams with in-memory reference
implementations. Pure deterministic TypeScript. No timers, no wall-clock, no
network, no browser/request lifetime anywhere.

## Deliverables

### packages/control-plane (NEW) — the command bus

- `@fleetos/control-plane`, private, Apache-2.0, `type: module`, exports map like siblings (`.`, `./queue`, `./ledger`, `./sla` — you choose the exact split), devDependencies: typescript + vitest (copy a sibling's package.json/tsconfig and adapt — e.g. `packages/evidence`'s).
- **Command envelope contracts:** `CommandId`, `CommandEnvelope` (tenant scope, command kind, payload, idempotency key, issued-at as `number`, audit ref), `CommandAck`, `CommandOutcome` (completed/failed/dead-lettered + reason codes).
- **Command queue:** submit (idempotency-key dedupe — duplicate submit returns the original ack, never double-executes) → ack → complete/fail; **retry policy as a pure deterministic function** (attempt schedule computed from attempt number, backoff basis points — integer math only); **dead-letter** after max attempts with reason code; drain semantics (a drain pass processes everything currently due at a given logical time `now: number`).
- **Execution ledger:** append-only entries with audit digests (reuse `digestOf` semantics — define locally if importing kernel types is undesirable at runtime; TYPE imports from `@fleetos/kernel` via `workspace:*` are permitted and preferred).
- **SLA/deadline tracker:** register deadline (command + due-at), evaluate breaches at a logical `now`, escalate deterministically (breach → escalation record with severity ladder).
- **Assignment + handoff records:** assignment (agent/actor ↔ command) lifecycle, handoff with acknowledgment, tenant fail-closed.
- **Reference transport:** in-memory port implementation modeling ack/timeout paths (like `makeReferenceTransport` in `packages/execution`, but control-plane-grade: outbox-backed).

### packages/mission (NEW) — the durable mission runtime

- `@fleetos/mission`, same package conventions; exports (`.`, `./journal`, `./runtime`, or your split).
- **Mission definition:** stages (ordered, optional parallel groups), per-stage guards (capability/predicate refs), checkpoints; validation of definitions (cycle-free, guard refs present, rejection codes).
- **Mission instance state machine:** `pending → running → suspended → completed | failed | cancelled` (+ per-stage states), legal-transition enforcement with rejection codes, idempotent transition application.
- **Mission journal (event-sourced):** append-only journal entries (stage started/checkpoint recorded/stage completed/mission suspended/...), each with digest; the mission state is a pure FOLD over the journal — replaying the journal reproduces state exactly; **resume semantics:** a suspended mission resumes from the last recorded checkpoint, never re-executes completed stages.
- **Work-order issuance:** a stage's execution intent is emitted as a command envelope (kind `work-order`) through the control-plane command queue CONTRACT — but implemented as a type seam (a `CommandSubmitPort`), NOT a runtime import of `@fleetos/control-plane` (mission must not depend on control-plane at runtime; the TL composes them — mirror how `actions` imports only TYPES from `@fleetos/policy`).
- **Outbox seam:** mission state changes emit outbox events through the kernel's `OutboxPort` TYPE (dual-write consistency law), with an in-memory reference adapter.
- **Determinism laws:** all functions pure; `now` is always an explicit input; no `Date.now()`, no `Math.random()`.
