## Deliverables (all five packages; keep exports additive, never break existing public shapes)

### packages/security — findings intake + posture as operational fold
- Findings intake pipeline: validate → dedupe (deterministic fingerprint) → correlate (same tenant/asset/kind+window) → triage; rejection codes at every stage.
- Posture computation as an event-sourced fold with checkpoint (posture is derived from findings stream, never stored as mutable truth).
- Remediation proposal lifecycle: proposed → approved → applied → verified, with evidence-gated transitions (a proposal cannot be `applied` without a verification evidence ref).
- Severity escalation rules (a `medium` finding repeated within a window escalates deterministically).
- Tenant fail-closed: no tenant scope → refuse with reason code.

### packages/policy — Guardian decision engine at operational grade
- Deterministic policy rule evaluation: ordered rules, allow/deny/escalate decisions, decision records with reason codes, precedence resolution, no floats in outputs.
- Capability grant chains: grant → verify → revoke with revocation propagation (a revoked intermediate invalidates derived grants deterministically).
- Decision audit refs (digest of inputs).

### packages/actions — action-plan composition
- Action plan → authorized command pipeline (plan validation, Guardian-gated emission, per-action idempotency keys).
- Plan lifecycle: draft → authorized → dispatched → settled (completed/failed/voided) with legal-transition enforcement.

### packages/execution — the command queue at truth grade
- Command queue: submit (idempotency key dedupe) → ack → complete/fail with retry policy (deterministic backoff schedule via pure function) and dead-letter after max attempts.
- Execution ledger: append-only, audit digest per entry, replayable.
- Transport port kept; reference in-memory transport extended to model ack/timeout paths.

### packages/evidence — canonical evidence bundles
- Evidence bundle format: content-addressed entries (sha-256 digests via a pure-TS sha-256 — check what F230A used in `apps/agent` and mirror the approach), bundle integrity verification, chain-of-custody refs.
- Verification records with outcomes and signer-free determinism (no wall-clock in outputs).
