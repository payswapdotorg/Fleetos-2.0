## Objective — give the fleet's assets a REAL industrial genealogy

Wave 7 proved the lane's journeys; Wave 8 hardened them for scale. Wave 9 adds the industrial-intelligence layer this lane owns: **material and method provenance** — which material lots went into which assets, which (versioned) methods were applied, and a tamper-evident lineage graph machine-run with deterministic traversal. All work is IN your existing packages (new `lineage/` modules inside `packages/assets` are the natural home), never new top-level packages.

### Deliverables — all pure deterministic TS; logical `now`/caller-supplied inputs everywhere

1. **Material lot domain** (`packages/assets/src/lineage/material.ts`): tenant-scoped material lots (lot id, kind, attributes, quantity + unit, logical timestamps); lot lifecycle (created → partially consumed → exhausted) with honest, reason-coded over-consumption refusals; deterministic per-lot digest (FNV-1a family — same family the repo's digest chains use).
2. **Versioned method domain** (`packages/assets/src/lineage/method.ts`): methods = operational/maintenance procedures with `(methodId, version)` identity and parameter schemas; method application records bound to REAL assets (validate against the assets kernel's `AssetId`/twin surfaces) with outcomes; deprecated versions stay readable (lineage is append-only history) but are refused for NEW applications with a REAL reason code.
3. **Lineage graph** (`packages/assets/src/lineage/graph.ts` + `lineage/queries.ts`): typed directed edges — `asset-consumed-lot`, `method-applied-to-asset`, `lot-transformed-into-lot`, `asset-replaced-by-asset`; deterministic edge ordering; **tamper-evident chain digest over the edge log** (any reordering/edit/rewrite of an already-chained edge must break verification — tested by mutation fixtures); traversal queries: full ancestry, full descendants, bounded-depth (documented bound), **cycle-safe** traversal with tested self-reference/cycle fixtures.
4. **Observation anchoring** (`packages/assets/src/lineage/anchor.ts`): a method application may reference a REAL observation record ingested through the observations package's public ingestion surface; dangling references are refused with reason codes (fail-closed).
5. **Tenant isolation**: cross-tenant lineage probes (traversal, query, application) fail closed with REAL reason codes — every NEW code path above gets a negative test.
6. **Tests ≥ 60 net-new** across your lane's packages: lifecycle refusals actually hit; digest tamper actually detected; cycle fixtures actually traversed safely; cross-tenant actually refused.
