## Deliverables (all three packages; exports additive only)

### packages/predictive — the deterministic reference twin model
- **Reference projection model:** given a twin state (structurally-typed input) + an observation history + a horizon, project forward deterministically. Pure function, integer/decimal-safe math, seeded pseudo-randomness only if needed (deterministic LCG keyed by input digest).
- **Provenance:** every prediction carries input refs (observation ids), model version, and an input digest — predictions are replayable and auditable.
- **Uncertainty:** deterministic confidence quantification — integer basis-point confidence + bound intervals (never floats in outputs where avoidable; document any float use).
- **Counterfactuals:** given a baseline history and a hypothetical intervention (structured what-if input), produce a divergent projection with divergence accounting (which outputs changed, by how much).
- **Advisory envelope:** a `Prediction` result type that structurally separates advisory values from authoritative inputs (advisory values can never be fed back as authoritative state — enforce by type shape).
- **Model adapter seam:** a `ModelPort` TYPE (external model adapters plug in later — Wave 5/F290B JEPA family) with an in-memory deterministic reference adapter implementing it. Reference model behind the port too.

### packages/world-model — the deterministic world state model
- **World state fold:** world state as a pure fold over world events (deterministic replay, checkpoint support) — mirrors the journal-fold pattern from `packages/mission` (read it as the pattern exemplar).
- **Entity projections:** world entities (assets/agents/orgs as opaque refs) with last-observation-driven state, staleness classification (fresh/stale/unknown by age thresholds — integer ms inputs).
- **Predictive integration:** TYPE imports from `@fleetos/predictive` (intra-lane, already established) — world model can ask the reference model for projections; keep advisory law structural.

### packages/world-context — tenant-scoped context assembly
- **Context assembly:** given world state + a query focus (tenant, entity refs, purpose), assemble a context record (feature snapshot with provenance refs) deterministically.
- **Privacy enforcement (tenant/privacy law):** context assembly is tenant fail-closed; cross-tenant refs are rejected with reason codes; field-level redaction rules (declarative redact-list per purpose) applied deterministically.
- **Context digests:** assembled contexts are digest-stamped for audit.
